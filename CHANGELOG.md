# Changelog

## 0.1.0

- Initial public-ready snapshot.
- Added a desktop remote directory workbench for SFTP, SCP, FTP, FTPS, and WebDAV.
- Added local and remote browsing, file actions, transfers, favorites, and terminal entry points.
- Added native CLI commands with stable `--json` output: `info`, `capabilities`, `browse list`, and `connections test`.
- Added public license and repository hygiene files.
